# 末廣家の家計簿 v4.1（夫婦共有・画面整理）

## 改善
- **夫婦共有済みの画面**：黄色の「部長の以前の記録を共有へ引き継ぐ」をトップから撤去。歯車の「設定」内に手動実行ボタンを置きました。
- **共有中表示**：家計簿トップに小さく表示。トップ写真は各自専用です。
- **保存状態**：保存処理中、接続エラー、オフライン、キャッシュ表示中などを区別して表示。
- **夫婦共有は維持**：収支・日別の記録写真を共有。既存のFirestoreルールを変更する必要はありません。

## 配置（iPhone）
1. まず部長・奥さんの両方で収支・写真が表示されることを確認してください。可能であればJSONで収支記録をエクスポートしてください。**JSONには写真が含まれません**。
2. ZIPを「ファイル」アプリで展開し、中のファイルをGitHubの `suehiro-kakeibo` リポジトリのルートへアップロードします。ZIPのままでは動きません。
3. Commit message は `Refine family sharing v4.1`、保存先は `main`。
4. GitHub Pagesの更新後、Safariで `https://suehiro3157369.github.io/suehiro-kakeibo/?v=41` を開きます。
5. 夫婦共有・記録・トップ写真が維持されているか確認。テスト記録を追加して、双方に反映されるか確認してください。

## 注意点
- 今回はUIと保存状態の表示が中心です。Firestoreのデータ構造やアクセスルールは変更していません。
- 以前の記録を再コピーする必要はありません。必要な場合のみ設定から実行してください。
- 自動保存でも通信障害や競合などによる失敗は起こり得ます。重要なデータは別途バックアップしてください。
- アプリアイコンを削除して再追加する前に、両端末のクラウド記録が一致することを確認してください。
