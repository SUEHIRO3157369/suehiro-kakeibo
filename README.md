# 末廣家の家計簿 v3.1

## 変更点
- 初回の端末内データ移行案内をトップから撤去。設定（歯車）からのみ移行できる。
- 移行時に既存のクラウド記録IDとトップ写真を上書きしない。
- ハート＋家の文字なしアイコンを追加（180/192/512px PNG）。
- Service Workerのキャッシュ名をv3.1に更新。

## 配置
1. このフォルダ内のアプリ用ファイル（HTML、JS、CSS、PNG、webmanifest、SVG）をGitHubのリポジトリルートへアップロードします。ZIPだけをアップロードしても動きません。
2. `firestore.rules` は参考用。すでにFirebaseコンソールから公開したルールを変更する必要はありません。
3. GitHub Pagesの反映後、SafariでいつものURLを開きます。PWAとして追加済みならキャッシュ更新のため閉じて開き直してください。
4. iPhoneのホーム画面のアイコンが旧画像のままなら、アプリのリンクをホーム画面から取り除いて、Safariで再度「ホーム画面に追加」してください。**アプリの削除・再追加で端末内の古いデータが失われる可能性があります。** クラウド保存済みを別ブラウザ等で検証し、必要なバックアップを取得してから行ってください。

## 動作確認
- 家計簿を開いた時に黄色い移行案内がない。
- 設定ボタンで移行機能を開ける。
- 既存の支出・トップ写真がクラウドから見える。
- ログイン後のデータはユーザーごとに分離。夫婦共有は今後の機能。
- JSONエクスポートには写真は含まれません。
