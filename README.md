# 末廣家の家計簿 v4（夫婦共有）

## 設定の順序（必須）
1. **まずFirestoreの「ルール」**へ `firestore.rules` を丸ごと貼り替えて「公開」する。ルール更新前にv4を公開しない。
2. GitHubの `suehiro-kakeibo` のルートにこのZIP内のアプリ用ファイルを展開してアップロードする（ZIPファイルそのものは不可）。
3. 部長のSafariでアプリを開く。ログイン後、本人の古い記録・トップ写真が残っているか確認する。
4. 「夫婦共有の設定」の「奥さんのUID」にFirebase Authenticationからコピーした奥さんのUIDを貼り付けて「夫婦共有を開始」。
5. 「以前の記録を夫婦共有へコピー（初回）」を押す。元の部長個人用Firestoreの記録・日別画像は削除せず、重複IDは上書きしない。トップ写真はコピーせず**本人専用のまま**。
6. 奥さんがご自身のiPhoneで同じURLを開き、奥さんのメールアドレスとパスワードでログイン。部長から渡されたUIDを「部長のUID」に入力し「共有に参加」。
7. 両方で同じ支出が表示され、片方でテスト入力するともう片方にも反映されることを確認。トップ写真はそれぞれ設定。

## 注意
- **Firebaseのルールは必須**。GitHubに `firestore.rules` を載せるだけでは適用されない。
- 同じ UID の保存済み個人データは残す。Firestoreコンソールで古い `users/` コレクションを消さない。
- 移行中は部長と奥さんで新規入力せず、まずコピー完了・件数を確認する。
- 失敗件数がある場合は再実行。空データが見えたからといって元のデータを削除しない。
- UIDは認証用の秘密そのものではないが、不特定多数に公開しない。
- 以前の端末内データの移行は設定（歯車）から手動実行可能。トップ写真は常に本人専用。
- 写真はFirestoreに圧縮して保存する。JSON書き出しには写真が含まれない。定期的に写真の別途バックアップを推奨。
- 実機動作確認前のため、まずテスト記録で同期を確認する。元のデータは消さない。
- 公開Webアプリなので、GitHubにメールアドレス、パスワード、UID入りのメモや画像をアップロードしない。
