# 末廣家の家計簿

家族写真をトップに設定できる、iPhone向けシンプルな家計簿カレンダーです。

## 機能
- 写真を端末から選んでトップに設定（IndexedDBに保存）
- カレンダーの日付ごとに収入・支出・メモ・写真（任意）を登録
- 当月の収入・支出・収支を自動集計
- 記録の削除とJSONエクスポート（※写真は含まれません）
- PWAとしてホーム画面に追加可能。読み込み後はオフラインでも利用できます。

## GitHub Pagesへの配置
1. GitHubで新しいリポジトリを作成します（例：`family-calendar-book`）。
2. このフォルダの全ファイルをリポジトリのルートにアップロードします。
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
4. 公開された `https://ユーザー名.github.io/リポジトリ名/` にSafariでアクセスします。
5. Safariの共有メニュー →「ホーム画面に追加」でアイコンから起動できます。

## 大切な注意
- 記録はSafariのlocalStorage、写真はIndexedDBに保存されます。端末やブラウザのデータを消すと記録が消える場合があります。
- 記録のJSONバックアップには写真が含まれません。別途元写真を保管してください。
- 現在はJSONを書き出す機能のみで、読み込み・復元機能は未実装です。長期利用や複数端末の同期には別途データ管理が必要です。
- GitHub Pagesで公開するのはアプリのコードのみで、家計簿の記録や写真はGitHubにアップロードされません。
