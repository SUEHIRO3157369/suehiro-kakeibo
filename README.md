# 末廣家の家計簿 v3 クラウド保存版

## 内容
- Firebaseメール・パスワードログインと次回以降のログイン状態維持
- Cloud Firestoreに収支記録・メモ・日付・カテゴリーを保存、過去月を表示
- トップ写真と記録添付写真を圧縮してCloud Firestoreに保存
- 保存状況とエラーを画面に表示
- 旧端末の家計簿記録・写真を確認してから手動でクラウドへコピー（元データは残る）
- 各ユーザーのUIDでデータを分離。**夫婦で共有する機能はまだありません**

## まずFirebaseのルールを設定（必須）
1. Firebase Consoleの `suehiro-kakeibo` → Firestore →「ルール」
2. `firestore.rules` にある全体のルールをコピーして既存ルールを置き換え、「公開」を押す
3. `allow read, write: if true;` のルールは絶対に使用しない
4. ルールはログイン中の本人の `/users/{uid}/...` のみアクセスできるようにする

## GitHubにアップロード
1. 既存のGitHub Pagesリポジトリ（SUEHIRO3157369/suehiro-kakeibo）を開く
2. このZIPを展開し、以下の**アプリファイルのみ**をアップロードして同名を更新する：
   `index.html`, `script.js`, `auth.js`, `style.css`, `sw.js`, `icon.svg`, `manifest.webmanifest`
3. `firestore.rules` やこの README.md はアプリ実行用ではありません。アップロード不要です
4. GitHub Pages更新後、Safariで通常URLを開いてログイン。必要なら `?v=3` を末尾に付ける
5. 「クラウドに接続済み・自動保存」が表示されるか確認する
6. 新規記録と写真を入力し、Safariを再読み込みして同じ内容が残るか確認する
7. 別端末でも同じFirebaseアカウントにログインすれば同じ内容が見られる（家族各自の別アカウントの共有は後日）

## 旧データのコピー
- 以前のSafari/ホーム画面アプリの記録と写真は別のストレージ領域にある場合があります。
- **既存データがある元のiPhone・起動方法で**アプリを開き、案内の「このiPhoneの記録・写真をクラウドにコピー」を押してください。
- このボタンはクラウドにコピーし、元のローカル記録を削除しません。同じIDなら上書きされます。クラウドのみの記録は消しません。
- 事前に既存アプリのバックアップ（文字データ）を取得し、元画像も別に保存してください。

## 注意点
- **写真もFirestoreの無料枠内に保存**するため、送信前にJPEGへ圧縮します。元の画質の完全保管ではありません。画像は最大約340KBに圧縮できない場合は保存に失敗します。
- Firebaseのデータベースを削除するとデータは失われます。定期的に別の場所へのバックアップが必要です。現行のJSON書き出しには写真が含まれず、写真込みのバックアップ復元は未実装です。
- 通信が必要です。完全なオフライン編集は未対応。アップロード成功表示を必ず確認してください。
- Safariのホーム画面追加版とSafari通常タブは別のローカル保存領域になり得ます。必ず元のデータがある方で移行してください。
- 公開GitHub Pagesに家計簿データ・写真は置きません。Firebaseのセキュリティルールで本人のデータのみ守ります。
- Firebaseに登録された**別々の2ユーザーは、このv3ではまだ別々の家計簿**です。夫婦共有するには家族単位のデータ構造と権限設定を追加する必要があります。
