# 末廣家の家計簿 v4.2 写真込みバックアップ

## 機能
- 歯車「設定」→「写真を含めたバックアップ・復元」から実行
- 夫婦共有の全収支、日別添付写真、操作中の本人専用トップ写真をJSONファイルへ保存
- サーバーから取得した状態をバックアップし、取得に失敗すればバックアップを成功扱いしない
- 復元は同じ共有先のみ。元データを消さず、同一IDの記録や写真を上書きせず、不足分だけ追加
- 自分で作ったバックアップのトップ写真だけ自分のアカウントに復元可能

## 更新手順
1. ZIPを展開して**中のアプリファイル**をすべてGitHubリポジトリのmainルートへアップロードする
2. `firestore.rules` は参考用。Firebaseコンソールで公開済みのルールを変更しない
3. GitHub Pages更新後、Safariで `https://suehiro3157369.github.io/suehiro-kakeibo/?v=42` を開く
4. 歯車 → バックアップを作成 → iPhone「ファイル」にJSONが保存されたか確認する
5. 復元機能は最初は何も復元せず、選択したファイル内容とアカウントを確認する。必要なときのみ復元

## 注意
- 写真は現在アプリが保存している**圧縮後のデータ**であり、元画像そのものではありません
- バックアップファイルには家計・写真など私的情報が含まれます。公開GitHubへアップロードしないでください
- バックアップは**手動**です。新しい記録を入れたら定期的に新しいバックアップを作ってください
- 大量の写真ではJSONが巨大化し、iPhoneのメモリ制限やFirestoreの容量・料金の上限にかかる場合があります
- 復元は不在IDの追加のみ。既存の内容を訂正・上書きする機能ではありません
- 夫婦が別々にバックアップすると個人トップ写真はそれぞれのファイルに含まれます
- 実機での復元テストは未実施です。まずバックアップが作成できることを確認してから本格運用してください
